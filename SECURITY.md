# Security Policy

## Supported version

Security fixes are applied to the latest version on the `main` branch.

## Reporting a vulnerability

Please avoid posting security-sensitive details, exploit instructions, or private information in a public issue.

If GitHub private vulnerability reporting is enabled for this repository, use that feature. Otherwise, contact the repository maintainer privately through an appropriate GitHub contact method and provide a concise description, reproduction conditions, and the potential impact.

For ordinary bugs that do not create a security risk, use the public bug-report template instead.
